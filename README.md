## デザイン

蒲焼きのタレ色(赤)と照りの金色をベースにした配色です。日替わりセクションは背景を赤と生成り色で交互に切り替え、写真とコピーの左右も交互に入れ替えることで単調にならないようにしています。

## 実装上のご注意

- JavaScriptは使用していません。HTML+CSSのみで完結しています。
- Google Fonts(Kaisei Opti / Zen Kaku Gothic New / Josefin Sans)を外部読み込みしています。
- 商品画像は各商品ページの掲載画像を使用しています。差し替える場合は `images/` 内の同名ファイルを置き換えてください。
- `index.html` 内のリンク(商品ページ・クーポンページ)は指定いただいたURLをそのまま使用しています。
